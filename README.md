## Naraak

**A Dedicated e-Services Platform for Primary Healthcare Centers — Kingdom of Bahrain**

Naraak is a UI/UX redesign project consolidating 12 Primary Healthcare Center (PHC) e-services — currently fragmented across Sehati, MyGov, and the MOH website — into a single, purpose-built platform. The project follows a research-driven, six-phase design and demonstration process:

- **Phase 1 — Research:** Heuristic review, patient/stakeholder interviews, and a quantitative survey to identify usability pain points.
- **Phase 2 — Strategy:** Service prioritization, target user segments, personas, and TO-BE journey maps built from Phase 1 findings.
- **Phase 3 — Sitemap & Wireframes:** Information architecture, service flows, user flows, and low-fidelity wireframes.
- **Phase 4 — Figma Prototype:** Interactive, high-fidelity UI/UX prototype for mobile and web, backed by a reusable design system.
- **Phase 5 — API Readiness:** API list, endpoint definitions, request/response models, authentication, error handling, and integration assumptions to guide any future production build.
- **Phase 6 — Flutter Demonstration:** Mobile and web Flutter prototype using dummy data to illustrate the proposed workflows (no live backend or production integration).

**Focus areas:** discoverability, reliability, and accessibility — ensuring booking, tele-appointments, medical records, certificates, and other PHC services are easy to find, trustworthy, and usable for all patients, including elderly and low-digital-literacy users. Targets WCAG 2.1 AA conformance with full Arabic/English bilingual support.

**Scope note:** This phase covers UX research, prototyping, and API readiness documentation only — no production development or live backend/eKey integration is included.
